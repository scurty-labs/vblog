Every element the Markdown renderer supports, in one place. Use this post to check typography, colour and spacing after changing a theme.

## Headings

### Third level heading

#### Fourth level heading

Headings, paragraphs, lists and tables all share one vertical rhythm, so a long post never drifts out of alignment.

A paragraph can mix **bold**, *italic*, `inline code`, a [link to vlang.io](https://vlang.io) and ~~struck text~~. Consecutive lines stay in the same paragraph, which keeps the HTML tidy.

> A blockquote gets a soft accent wash and a coloured rail.
>
> It can hold several paragraphs, or a list:
>
> - first point
> - second point

### Lists

Unordered lists keep their markers close to the text:

- Espresso
- Flat white
  - extra shot
  - oat milk
- Filter coffee

Ordered lists number themselves and indent nested items the same way:

1. Draft the post
2. Preview it
3. Publish it

### Code

Inline code looks like `v run .` and blocks keep their own surface:

```v
fn main() {
	println('Hello from V')
}
```

### Tables

| Element | Style |

| Headings | Tight leading with an accent rule |
| Quotes | Accent rail and a light wash |
